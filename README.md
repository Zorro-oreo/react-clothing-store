# React Clothing Store

A multi-page clothing brand website built with React.

## Features
- Hero section with a product of the day that changes daily and a seasonal tagline
- Shop page with product listings, and a lookbook page for the new collection
- Add to cart, with both a cart page and a sliding cart menu
- A care page and a full-screen mobile menu

## Tech
React, react-router-dom, react-bootstrap. Route-level code splitting with React.lazy, and cart state managed with the Context API.

## Run locally
```bash
git clone https://github.com/Zorro-oreo/react-clothing-store.git
cd react-clothing-store
npm install
npm run dev
```

## About
Final project for ITI's Web Development using React program (Jul to Aug 2026).
Product data is loaded from a local JSON file; there is no backend or authentication.
The brand, products and testimonials are fictional sample content.
